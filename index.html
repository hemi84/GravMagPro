About GravMagPro

GravMagPro is a commercial, fully functional desktop window application for the processing and analysis of gravitational and magnetic field data, specifically designed for oil & gas, mineral exploration, and other geophysical surveys. Delivered as a standalone desktop program with an intuitive graphical interface, it offers an industry-standard suite of tools that streamline data processing and enhance decision-making in exploration projects — with no coding required. For developers, researchers, and scientists who prefer a scriptable, notebook-driven workflow, GravMagPro also remains available as a Python package.

⬡ Magnetic Vector Inversion (MVI) Suite — Why It Matters

Conventional magnetic inversion assumes magnetization is aligned with the Earth's field — an assumption that breaks down wherever remanent magnetization is significant. The Magnetic Vector & Amplitude Inversion Suite recovers the true magnetization vector independent of direction, delivering geologically reliable subsurface models where standard susceptibility inversion produces misleading or inconclusive results.

This capability is especially valuable across several exploration settings:

  • Porphyry copper systems with strong hydrothermal remanence
  • Banded iron formations and other iron ore deposits
  • Massive sulphide bodies with self-demagnetization effects
  • Kimberlites and other remanence-dominated intrusives
  • Amplitude inversion for reconnaissance-scale, direction-independent targeting
  • Any survey area with suspected or historically documented remanent magnetization

Installation

To install gravmagpro, run the following command:

For local installation using a wheel package:

For a .tar.gz distribution file:

pip install /path/to/grav-mag.tar.gz
